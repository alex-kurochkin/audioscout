# Правила выполнения задач (обязательно соблюдать)

- **Запрещается только описывать действия.** Не допускается использование текста типа «я сейчас выполню...», «следующий шаг — ...» для замены фактического вызова инструмента. Любое изменение файла, выполнение команды или чтение кода должны быть реализованы через фактический вызов инструмента.
- **Каждый шаг должен иметь проверяемый результат.** После завершения задачи необходимо явно перечислить конкретные выполненные операции (например: «выполнено X, изменён файл Y»), а не ограничиваться общим утверждением «задача выполнена».
- **При обнаружении незавершённости необходимо явно указать на это.** Если из-за ограничения контекста, ошибки инструмента или других причин задача не может быть продолжена, необходимо прямо написать «задача не завершена, причина: ...», а не выдавать её за выполненную.
- **Перед вызовом инструмента не нужно произносить длинные предисловия.** Сначала выполните операцию, затем кратко объясните результат.
