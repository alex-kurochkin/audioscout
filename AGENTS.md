Никогда не меняй файл .gitignore без прямого разрешения.

При первом запуске диалога проанализируй репозиторий.
В файле tz находится техническое задание на момент начала разработки.
Установи необходимые зависимости для компиляции и запуска тестов.

Всегда вноси изменения в код.

В конце задачи запускай компиляцию и тесты:
cargo build
cargo test
Сборка и тесты должны проходить без ошибок и warning-ов.
